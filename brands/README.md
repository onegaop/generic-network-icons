## SafePal

- Owner: SafePal.
- Official source and usage guidelines: https://www.safepal.com/en/brandassets
- Official artwork package linked from that page: https://www.safepal.com/pub/SafePalLogoFiles.zip
- Source artwork: SafePal Logo Files/Logomark/SVG/Mark - Color.svg.
- PNG is a faithful native vector rasterization of the supplied artwork. Original geometry and official purple are preserved; transparent outer space is one half of the mark's size on each side, following the official clear-space guide. No AI reconstruction or recoloring.
- Follow SafePal's guidelines, including proportion, palette, legibility and non-endorsement requirements. This repository does not grant trademark rights or a general redistribution license.
